# 浏览器代码编辑器

项目工作区的「文件」以及公开分享页的「源码」使用 Monaco Editor 0.56。它提供 VS Code 风格的编辑体验，不需要用户安装桌面 VS Code，也不包含桌面扩展市场或终端。

## 操作

- 左侧资源管理器、文件夹折叠、顶部文件切换与路径面包屑。
- 标签只显示已打开的文件，点击叉号关闭，关闭当前标签会选择相邻标签；全部关闭后可从目录重新打开。关闭不删除项目文件，未保存修改会提示继续编辑或放弃后关闭。
- 语法高亮、代码折叠、括号配对、缩进参考线、多光标、语言补全。
- `Ctrl/Cmd+F` 查找，`Ctrl/Cmd+H` 替换（平台默认键位），`Ctrl/Cmd+S` 保存为项目新版本。
- 撤销、重做使用编辑器默认快捷键；工具栏可切换自动换行、折叠目录或放弃未保存修改。
- 未保存时保留当前文件并提示先保存或放弃，避免切换文件造成草稿丢失。保存期间暂时锁定编辑，失败保留草稿。
- 分享页、查看者和生成中的代码沿用现有只读权限。底部显示保存状态、语言和光标位置。

## 实现边界

`src/lib/monaco.ts` 随站点打包编辑器与 JS/TS、JSON、CSS、HTML worker，无 CDN 依赖。首次显示文件区域才加载，隐藏面板保留编辑器和光标状态；离开页面时释放编辑器和模型。各实例使用独立文件 URI，避免不同项目的模型和撤销记录混用。

JS/TS 启用语法诊断、补全和语言服务。浏览器没有项目的 node_modules 类型环境，因此关闭语义诊断，避免把未载入的第三方类型错误展示为项目编译错误；保存仍通过原有代码验证与版本保存流程。

加载失败会降级为可编辑、可保存的文本框，不自动刷新页面或清空输入。网络恢复后，先保存修改，再刷新页面即可重新加载。深浅主题随站点设置切换。

## 验证

在 `app/frontend` 中运行：

```sh
pnpm test:editor
pnpm test:editor --production
pnpm exec tsc -p tsconfig.app.json --noEmit
pnpm lint
pnpm build
```

浏览器测试默认使用本机 Edge，可通过 `PLAYWRIGHT_CHANNEL` 选择其他已安装的 Chromium 通道。测试在独立 Vite 服务中运行 `scripts/fixtures/editor.html`，不访问项目 API、账号或真实用户数据。覆盖延迟加载、本地 worker、撤销重做、草稿保护、查找替换、补全、保存锁定、失败保留、只读、主题切换、卸载重建与断网文本降级。`--production` 额外验证实际打包后的 worker 和编辑器。
