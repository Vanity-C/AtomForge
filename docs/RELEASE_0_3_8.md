## 本次行为调整

回滚直接恢复所选快照的文件、入口文件和当前版本号，不新增版本，不删除或改写其他历史快照。例如已有 v1–v5 时回到 v2，版本历史仍为 v1–v5；继续生成或手动保存时创建 v6。旧实现产生的回滚快照继续保留。
