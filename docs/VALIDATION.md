# v0.1.0 发布验证

本页记录实际执行的检查，不以功能清单替代测试结果。

发布前检查进行中；测试数量、服务器健康和公网体验结果在验收后补齐。

## 验证范围

- 后端：账号唯一性、权限隔离、项目生命周期、版本、团队协作、决策卡、生成恢复和集成协议。
- 前端：类型检查、静态检查、会话和文件显示状态逻辑。
- runner：真实构建及浏览器测试协议。
- 部署：HTTPS、未登录入口、真实模型生成、数据持久化、公开发布链接、数据库备份。

## 范围限制

模拟的第三方接口测试不代表真实 GitHub 应用同步、Stripe 支付或 Tavily 服务已验收。当前服务器的单次流程检查也不是容量或负载测试。
