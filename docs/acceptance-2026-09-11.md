# AtomForge Demo 验收记录与体验路线

验收日期：2026-09-11。

## 对照挑战标准

| 要求 | 实现及验证 |
| --- | --- |
| 可运行网页与类似 Atoms 的交互 | 对话、代码文件树、编辑器、沙箱预览、版本和分享工作台；本地与在线首页已打开 |
| 智能体驱动应用生成 | DeepSeek 真实生成“紫韵待办”，再通过对话新增深色模式；没有使用预置代码冒充模型结果 |
| 真实交互 | 浏览器验证添加任务、深色模式切换；刷新后任务恢复 |
| 数据持久化 | SQLite 保存账号、代码、对话、版本；服务重启后恢复。生成应用的业务数据通过沙箱桥接保存到浏览器 |
| 初始化、注册、核心主流程 | 本地注册/登录、首次生成、继续修改、保存、预览已验证；在线浏览器登录成功，在线生成客户端也通过真实 API 流程 |
| 至少一个延展能力 | 版本回滚、只读分享、完整工程导出；回滚和关闭分享通过隔离数据库测试，导出后的真实项目独立构建通过 |
| 在线可测试链接 | 临时 HTTPS 链接已建立，页面/路由/依赖/登录/模型增量生成/项目保存/分享已做网络验证 |

## 三分钟体验路线

1. 打开在线工作台，注册账号或使用交付消息中的体验账号登录。
2. 输入：`做一个待办应用，支持新增、完成、删除和筛选，刷新后保留数据。`
3. 查看代码逐步生成，结束后等待右侧显示“运行中”；添加一条任务并刷新。
4. 继续输入：`保留现有任务，添加深色模式切换。`
5. 切换主题，在“版本”中选择旧版本并回滚，查看生成代码与界面的变化。
6. 点击“分享”开启只读链接，在未登录窗口查看；关闭分享后链接应不可访问。
7. 点击“导出”，解压后执行 `npm install`、`npm run dev`；或执行 `npm run build`。

## 已执行的检查

- `pytest app/backend/tests -q`：账号鉴权、账号间隔离、代码版本与回滚、分享打开/关闭、生成参数限制、取消和配额限制。
- TypeScript 类型检查、ESLint、Vite 构建通过。
- 浏览器实际调用 DeepSeek：首次生成待办应用，第二轮增加深色模式；新增任务后刷新仍在，新版本保留原有数据。
- 通过临时 HTTPS 链接运行应用同一套生成客户端：登录、创建后台任务、增量读取、解析两份代码文件、保存“在线验收计数器”、开启分享均成功。
- 真实待办源码通过同一导出逻辑生成独立工程，安装依赖后 Vite 构建成功。
- 网络检查：页面、项目直达链接和本地预览依赖返回 200；匿名项目 API 返回 401；环境文件返回 404。

浏览器自动化在后半程出现连接超时，因此在线页面深层交互的自动化覆盖有限；在线生成与分享接口流程另有真实网络验证，不能把接口验证等同于全部浏览器端到端操作。

## 交付边界

- 临时链接依赖当前电脑、网络及隧道进程；重新开启隧道可能改变地址。
- 当前是单 worker 的 Demo，生成任务与限流计数在内存中；已保存项目落 SQLite。
- 预览支持 React/JSX/CSS，不支持任意 npm 包、服务端应用或容器。
- 生成应用业务数据保存在当前浏览器；不同设备/域名不自动同步。代码和对话则属于服务端账号数据。
- 已提供人工点击的“让 AI 修复”入口；尚未实现无需用户介入的多次自动修复循环。
- 模型偶尔可能生成运行错误。此时能看到错误、重试/请求修复或回滚，不能保证任意需求一次成功。

后续可选：长期服务器部署、数据库版本迁移、跨设备同步、后台生成任务恢复、更多运行时依赖支持。
